# JNUC-2026
Directory of notes from the JNUC 2026 Presentation "1220 - OS Updates at a Glance: Visualizing Fleet Health and Compliance at Scale"

update_extension_attributes clean.py is the script that updates all the extension attributes OS Health and Computer Lock Status. To use the script, update the Extension Attribute ID and Advanced Search ID to the ones created in your own Jamf Server.
